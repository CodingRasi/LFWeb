# Lingofisy website

Informational, static frontend for [lingofisy.com](https://lingofisy.com). This site has no backend, accounts, or secrets and is designed for GitHub Pages.

## Local preview

```bash
python3 -m http.server 4173
```

Open http://localhost:4173.

## Before launch

- Replace bracketed fields in `legal/imprint.html`, `legal/privacy.html`, and `legal/terms.html`.
- Replace the app-store placeholder links in `index.html` when listings are live.
- Review the legal pages with a qualified adviser.
- Enable GitHub Pages for the repository and configure Strato DNS.
